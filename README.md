# Фильтр частиц для отслеживания объекта в одномерном пространстве на языке C

## Описание

Данный проект реализует простой одномерный фильтр частиц для оценки скрытого положения движущегося объекта по зашумлённым измерениям. Проект демонстрирует принципы байесовской фильтрации и численного моделирования динамических систем.

## Основной функционал

* **Модель движения**: Объект движется по прямой с постоянной скоростью и случайным шумом процесса.
* **Модель измерений**: Датчик выдаёт зашумлённые показания положения объекта.
* **Фильтр частиц**:
    * **Инициализация**: Создание N частиц из априорного распределения.
    * **Предсказание**: Движение частиц согласно модели с добавлением шума процесса Q.
    * **Обновление весов**: Вычисление правдоподобия каждой частицы на основе измерения z и шума датчика R.
    * **Нормализация**: Приведение суммы весов к единице.
    * **Перевыборка**: Систематическая перевыборка частиц с учётом их весов.
    * **Оценка**: Вычисление взвешенного среднего положения.
* **Вывод результатов**:
    * На каждом шаге выводятся: истинное положение, измерение, оценка фильтра.
    * Данные сохраняются в CSV-файл `output/output.csv`.
    * Вывод статистики: среднеквадратичная ошибка (RMSE).

## Сборка и запуск

Для сборки проекта используйте Makefile:

```bash
make
./bin/particle_filter
```
Для запуска тестов введите команду:

```bash
make test
./bin/test
```
